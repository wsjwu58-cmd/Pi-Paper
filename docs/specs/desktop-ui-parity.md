## 2026-09-29 Agent 面板差距核对

对原 `AgentPanel`、桌面 `useDesktopAgentController`、preload/IPC 和 Worker 的源码核查发现，Agent 面板仍有以下 1:1 缺口，不能以“复用原面板”视作完成：

- 桌面历史页能列出并恢复本地会话，但未迁移 Web 历史页的“保存当前会话片段”和“导入可复用片段”能力。
- 桌面 Skill 列表只来自 `SYSTEM_SKILLS`；项目自定义 Skill 的创建、导入和管理没有本地实现。UI 已禁用“新建”并提示该限制。切换历史会话时会重新读取当前会话已加载的 Skill 状态。
- 当前轮的节点引用 ID 会传入本地 Agent Run，实时用户消息也会显示引用卡片；Pi JSONL 历史只保存角色、正文和时间，引用卡片元数据没有持久化。应用重启后旧消息无法恢复这些卡片。
- 桌面设置入口显示 Agnes Key 与云端数据发送披露，没有接入原 PreferencesTab 的图像/视频默认模型、默认分辨率和长期记忆查看/删除界面。这些界面及对应本地能力仍是缺口。
- 当前确认操作的 `confirmAgentAction` 已由 preload 暴露，经 Main 校验项目、画布、令牌和版本后进入 Worker 确认服务；源码存在端到端桥接，但本次核查未做真实生成确认的窗口录屏验收。
- 异步 `run_failed` 事件现显示清理后的可读错误；会话切换会刷新已加载 Skill 状态，确认或终态事件会刷新本地历史标题与排序。聚焦事件测试通过，不代表窗口交互和完整 Agent 链路验收通过。

## 基线与例外

除 Agent 的上下文压缩、短期记忆、长期记忆及恢复能力外，桌面版沿用旧 Web 的可见界面、布局、组件、操作入口、状态反馈和结果呈现。Agent 面板的可见对话体验也沿用原版。**实现方式是直接以 `pi-paper-web/src` 原页面/组件源码为迁移基线并在原代码上改造**：本地 API、IPC、状态和事件通过明确适配接入 `CanvasPage`、节点/编辑器和 `AgentPanel`；不另建平行 `DesktopWorkspace`、`DesktopAgentPanel` 或简化节点实现来替代。Electron 窗口壳、preload/IPC 和本地服务适配可独立实现；共享 UI 中的平台差异须保持显式，且不得改变 Web 默认路径契约。桌面只替换本地数据、模型和任务适配层，以及明确移除的注册登录、平台计费、企业、运营、公开发布等能力；不得以迁移为由新增独立任务抽屉、逐次 API 发送确认或不同风格的节点编辑器。

本清单只记录可见界面的对照；完成条件还包括原项目后端能力和语义 1:1 对齐。Canvas/Asset/Generation/Agent 的领域校验、节点与连线规则、分组堆叠、素材引用、生成参数、任务状态与恢复、Agent 工具及 Skill 均须用原服务测试场景对照本地核心。未实现的后端功能即使界面相同，仍属迁移缺口。

## 云端调用

模型配置处说明提供方、会发送的数据范围、是否联网和可能的供应商费用。用户主动选择云端模型并点击发送后直接进行普通对话 API 调用；不对每次普通 API 请求弹数据发送确认。Agent 提交生成任务仍保留原版单个/批量生成确认界面，确认后才提交任务，界面去掉点数消耗与冻结文案。Agnes 图片参考按原适配发送；Ark Seedance 2.5 会收到用户提供的提示词、图片参考，以及视频/音频参考的 HTTPS URL。节点入口说明本地视频/音频尚不能上传，提交前拒绝，不向 Ark 发送本地路径或字节。模型设置需披露供应商和可能费用。仅选择本地模型时不发送外部请求。删除/覆盖等高风险画布写操作仍按 `AGENTS.md` 的可撤销或确认规则处理。

## 验收方法
