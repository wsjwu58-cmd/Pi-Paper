# VibePaper 桌面本地版 Agent 功能规格（提案）

> 日期：2026-09-24。状态：桌面 Agent 功能与验收契约；实现进行中。本地存储、备份/恢复、Worker 生命周期、会话历史查看，以及逐条确认后发送到 Agnes 的文本回合已有原型；云端文本回合会附带当前画布的只读摘要，确认框展示实际摘要内容。摘要只含受限长度的文本节点正文、图片/视频节点名称和连线，不附加媒体文件、应用存储的项目路径或内部标识；画布版本变化会使待发送回合中止。开发版 Electron 已在当前 Windows 环境启动；多平台安装包、画布/素材/任务工具与 Tool Gateway、本地模型回合、记忆/压缩和端到端验收仍待实现，Agnes 云端回合待完成用户确认后的连通性实测。本文规定目标行为，不代表所有条目已交付。对应技术方案见 [Agent 本地化迁移设计](../plans/2026-09-23-local-agent-migration-design.md)，全服务范围见 [桌面本地化方案](../plans/2026-09-23-desktop-full-service-local-migration-plan.md)。根目录 `AGENTS.md` 是桌面版工程契约；旧 Web PRD 与 V1.0 Spec 仅供迁移对照。

## 1. 产品边界

桌面版是**单用户、本地项目文件优先的创作工具**。画布、节点、连线、素材原件和生成结果、生成任务、Agent 会话、工具记录、Skill、记忆、设置、运行日志和备份都由本机持有；不要求注册、登录或连接平台服务器才能打开项目、继续会话及使用已安装的本地模型。Agent 不能因为无网络自动退回云端 Agent、云端存储或云端生成。

首版同时支持本机模型和用户配置 API Key 的云端模型。默认模式为“本地处理”：只调用本机模型/生成器，项目数据不作为遥测、同步或模型请求发送到外部地址。第三方 API 是用户**显式启用的独立联网模式**：在启用前说明供应商、将发送的数据类型、供应商可能收取的费用、隐私边界；每次使用按设置显示明确的联网标识。联网模式可以把结果保存回本地，但不能再宣称“数据仅在本地处理”。不把可联网等同于引入平台账户、点数或云端会话存储。

桌面版不包含平台点数、冻结/结算/充值、订阅套餐、签到奖励、邀请返利、企业配额、运营审核、共享云端记忆或远程 Agent 服务。Token 用量可继续统计，但只作为本机资源/模型调用信息，不能叫“点数”或“余额”。非 Agent 模块和整体产品导航按全服务方案处理；创意广场源码保留但入口关闭。不迁移旧 Web 数据，也不删除旧代码或旧用户数据。

## 3. Agent 对话与创作行为

1. 当前项目、画布和用户选中节点由桌面宿主显式交给 Agent；每条引用带稳定节点标识和画布版本。Agent 不根据画布空间位置猜测创作依赖。
2. Agent 通过工具白名单读画布/素材/模型能力，通过 Tool Gateway 写入；不能直接改画布 JSON、SQLite 表或本地文件来绕过领域校验。节点能力、输入角色、模型 `inputMode`、参考图上限和顺序在执行前校验。
3. 用户明确要求一对一时，按目标逐项声明唯一来源；三个分镜对应三个视频时生成三条语义正确的连线，不做 3×3 笛卡尔积。来源、首帧/尾帧角色或排列不明确时，先提问，再创建/删除相关节点。
4. 本地生成任务可异步运行。Agent 只在本地 TaskStore 标记成功且结果文件可读取后宣布完成；本地模型缺失、资源不足或失败时显示具体状态，不静默启用外部 API。
5. 继续保留高风险操作的可见预览和确认边界。按桌面版 `AGENTS.md`，删除/覆盖不可撤销内容须可撤销或显式确认，清空画布和批量写入超阈值先确认，画布版本变更后旧确认失效。移除“预计点数 ≥1”这种计费触发条件。启用联网模型时，发送项目内容必须有用户事先授权。
6. 面向用户的回复只说创作对象、结果和待办，不暴露内部节点 ID、工具名、账本键或存储路径。取消、关闭面板和重启后可从本地会话与任务状态恢复。

## 4. 数据与记忆功能

| 数据 | 保存位置与生命周期 | 用户能力 |
| --- | --- | --- |
| 完整对话、Pi 工具调用/结果 | 项目内 JSONL，压缩不删除原文 | 查看、继续、导出、删除会话 |
| Run、确认、幂等、任务关联 | 项目内 SQLite；本地业务状态仍由各自存储负责 | 查看进行中/失败任务，安全重试 |
| 压缩摘要和会话工作状态 | JSONL compaction 记录 + 可重建检查点 | 重启后继续；必要时重新读取原始事实 |
| 会话记忆 | 项目内 `session-memory/<id>/memory.md` | 查看当前会话连续性信息 |
| 项目/画布偏好 | 项目内 `memory/*.md` | 查看、编辑、删除、导出 |
| 全局用户偏好 | 本机用户数据目录 `memory/*.md` | 查看、编辑、删除；不自动同步其他设备 |
| 当日临时记忆 | 本地文件或 SQLite，按明确到期时间清理 | 查看或清除 |

显式“记住/以后默认”可写入非敏感长期偏好；从普通对话推断的习惯先作为候选，不自动成为事实。画布节点是否存在、任务是否成功等只从本地权威业务存储核验，不能靠记忆或摘要决定。记忆文件属于低信任资料，不可覆盖当前用户指令、系统规则或工具权限。存储密钥时使用操作系统凭据能力，不写普通 Markdown/JSONL；会话导出前提示其中可能含提示词、素材信息和工具结果。

## 5. 上下文压缩与断点恢复

每次调用模型前，以完整上下文窗口扣除 system、工具、Skill、当前用户请求、记忆、输出预留和安全余量，再给历史分配预算。大工具结果先落盘并留下可回查引用，旧结果再转短占位；仍超预算时仅在完整轮次边界摘要旧历史，保留近期工具调用与结果配对。压缩仅改变模型输入视图，不裁剪原始 JSONL。

断点恢复读取上次有效 compaction、之后的完整轮次和本地任务状态。写画布/提交生成前先写持久化操作意图与幂等键；崩溃后先核验本地业务结果，不能重放已成功工具。离线是默认可运行状态；若本地模型未安装则显示安装/配置缺失，而不是切换云端。项目目录移动后通过稳定项目标识恢复会话，不依赖绝对路径作为身份。

## 6. 验收条件

- 无账户、无网络、无 PostgreSQL/Redis/Nacos/Docker 的桌面环境中，可打开项目和历史会话；本地模型及生成器已安装时能完成创作。缺少本地模型时明确报缺失，不上传内容。
- 创建文本分镜后经历至少 50 条消息、一次压缩和一次进程重启，Agent 仍能定位正确分镜与画布版本；工具原文可从本地日志找回。
- 三个分镜各创建一个视频节点，形成 1:1 连线；输入关系不明确时先问用户，不先删除旧节点或写错误连线。
- 对工具成功但会话落盘中断、任务已创建但响应丢失、JSONL 尾行损坏和项目搬迁进行恢复测试；不会重复创建节点或生成任务。
- UI、Agent 回复和本地任务记录不出现平台点数、余额、充值、签到、套餐、企业配额；Token 用量若展示，明确与本机/第三方模型调用有关。
- 检查默认本地模式的网络出口：没有会话、素材、提示词、日志、遥测或模型请求离开本机。首版云端模式单独验收供应商/发送范围告知、用户授权、Key 安全存储和断网/Key 无效错误。
