# 裁剪、框选编组与生成反馈

## 范围与实现方案

本轮根据用户提供的五张参考图修改原 `CanvasPage`、节点工具栏与节点展示组件。新增能力经现有本地画布、素材与任务适配运行，不引入平行桌面页面或云端裁剪。

### 图片裁剪

- 工具栏进入裁剪状态；支持单图、2×2、3×3。
- 用户移动或缩放覆盖在原图片上的裁剪区域，区域不得越界。显示坐标转换为原始图像像素，按行列切分并生成 PNG，保留完整像素覆盖。
- Renderer 不获取任意磁盘权限。PNG 经受限 `saveCanvasImage` IPC 校验项目、画布、源图片节点、格式、字节大小与尺寸后交由本地素材导入。
- 保留源图片，裁剪结果是可独立拖动的图片节点，并加入编组；单图裁剪也有组框。

### 编组

- 选择模式下拖动框选，全包含的节点形成编组；抓手模式继续用于平移。
- 编组浮动工具支持水平排列、垂直排列、取消编组和下载。框选与组框的展示节点不作为真实业务节点落盘。
- 成员位置与组成员列表通过原画布快照保存，重开后恢复。垂直布局以真实坐标保存，兼容原后端已支持的 layout 值。
- 桌面组下载先刷新画布持久化，再以本地权威组成员解析产物；一次选择目录，将现有结果保存到独立子文件夹。取消不创建输出，变化后的组不沿用旧快照，项目内部数据目录不可作为导出位置。

### 生成反馈

- 根据真实任务排队/运行状态显示阶段和耗时；没有供应商进度值时不伪造百分比。
- 有可用上游参考图时作为生成中的背景，叠加动态点阵与扫描效果；输入连线通过 CSS 动画体现流向目标。
- 使用持久任务时间计算耗时，终态立即清除忙碌效果。已有产物的再次生成同样显示状态。
- 动画仅属于视图，不写入任务或连线领域状态；支持减少动态效果的系统设置。

## 验证记录

### 交互修正

- 编辑器展开只由明确点击的编辑目标控制；框选和拖动的 React Flow 选择状态不展开六类节点。开始框选/拖动时收起编辑器，避免节点尺寸影响选区。
- 独立拖动成员时固定拖动前的组框范围；松开后以节点中心是否超出原框判断脱组。同步清除节点两处 groupId，剩余成员保留，空组移除，正常快照保存成员关系。
- 组框统一显示黑色。生成参考连线保留蓝色实体底线，以独立白色高光描边沿曲线路径流动，支持减少动态效果设置。
- 修正后 16 项相关测试与生产构建通过，新增用例覆盖框内移动、框外脱组、单成员空组以及尺寸和其他成员保持。隔离窗口确认黑色组框；本次拖动自动化未获得有效输入验证，因此不列为手工交互通过证据。

- `pi-paper-web` 生产构建通过；裁剪几何、编组范围/排列/成员关系、跨画布异步防护、生成状态与节点下载测试共 21 项通过。
- 桌面裁剪保存与编组下载、节点产物下载测试共 14 项通过，覆盖目录取消、项目切换、成员变化、内部目录保护和 React Flow 快照节点解析。
- 隔离 Electron 用户目录运行原页面、真实本地核心和素材存储：拖动/调整裁剪区域，切换四/九宫格后保留区域；创建九张及四张真实 PNG 节点；四张组内 PNG 下载实际落盘；水平/垂直排列及取消编组生效；重开保留裁剪节点和编组。
- 实测修复两处问题：完整画布保存后的 React Flow 节点需要规范化才能解析下载源；框选编组后清除多选状态，避免选择层遮挡组工具栏。裁剪遮罩限制在源图片内。
- 生成视觉使用明确的本地运行/取消状态 fixture 验证：上游参考背景、扫描点阵、输入连线动画和递增计时均显示，终态清除效果；没有提交付费模型请求，不代表供应商生成验收。
- 隔离壳替换了 Agent Worker 生命周期响应，画布/素材/保存/下载走真实核心；本记录不构成 Agent 初始化或完整 Agent 链路验收。单图像素切分及单成员组由定向测试覆盖，跨平台安装包仍需独立验收。
