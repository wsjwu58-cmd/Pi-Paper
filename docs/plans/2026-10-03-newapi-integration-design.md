# New API 网关接入设计

> 历史讨论，用户最新决定恢复 Pi 二次开发。本文件不再作为运行契约；当前方案见 [Pi 官方接入实施设计](2026-10-03-pi-official-provider-implementation.md)。

日期：2026-10-03。用户最新决策：由 New API 替代此前 Pi 原生多厂商扩展及 LiteLLM 方案。本文为当前实施方案；真实网关与供应商验收尚未完成。

## 部署与职责

用户自行部署 New API，创建渠道、填写厂商官方凭据、配置模型映射和所需任务插件，再创建受限调用令牌。VibePaper 只配置服务地址与这枚令牌，不索取网关管理账号、不代部署、不将 New API 内置安装包、不同时串联 LiteLLM。桌面应用和本地创作仍可离线启动，既有 Agnes 官方、Ark 与本地路径保留。

调用链：原画布/Agent → 受限 IPC → 本地 Provider Registry 与 TaskStore → 受控生成 Worker → 用户 New API → 上游模型。Pi 继续承载原 Agent 会话、工具、压缩与记忆；文本通过其 OpenAI 兼容模型描述连接网关。媒体由桌面适配器调用明确的网关协议，结果由 TaskStore 对应的项目目录保存。

## 配置与模型选择

配置页沿用参考图一的大卡片布局。连接详情包含服务地址、掩码令牌、超时、测试连接/同步模型、已启用模型、四类默认模型、发送范围与费用说明。公网使用 HTTPS；HTTP 只允许显式本机 loopback。秘密经操作系统安全存储加密，不回传 Renderer，不写普通设置、日志、会话或项目导出。

同步使用 `GET /v1/models` 和当前令牌，展示实际目录；权限错误与网络错误必须明确显示。目录仅表明模型可见，不证明图片编辑、首尾帧、音乐、克隆或变声等操作。每个模型绑定记录稳定本地 ID、真实网关模型 ID、展示名称、品牌、模态、操作、输入能力、默认参数、约束；异步任务还记录插件 key 与核验版本。未识别项需用户分类后才能启用，不通过名字猜测完整能力。

画布选择器沿用参考图二的厂商/模型两列与本地官方品牌图标。网关连接身份和上游品牌分别记录；同一品牌经不同连接的绑定不能混淆。仅已配置、启用、适配已实现并输入能力匹配的绑定出现在画布中。固定“自定义配置”按钮进入配置页，通过导航 state 保留原画布、节点和编辑位置。当前节点的模型失效时显示原因，不自动替换或跨渠道重试。

原 20 文本、16 图片、25 视频、11 音频共 72 项仍为目标；原视频标题写 26 项但正文实际 25 项。目标清单不预置成全部可用，也不将品牌展示名称直接充当调用 ID。默认 Claude Fable 5.1、Seedream 5.0 Pro 和 Seedance 2.5 仅在相应绑定实际可用时应用；否则保持未选择。首尾帧、参考数量、时长、分辨率与音频生成等参数逐项核验。

## 协议边界

| 操作 | 接入路径 | 开放条件 |
| --- | --- | --- |
| 文本/Agent | `/v1/chat/completions`，Pi 兼容协议 | 普通文本可用；Agent 另须工具调用、流式和上下文能力 |
| 图片生成 | `/v1/images/generations` | 绑定对应操作与网关参数 |
| 图片编辑 | `/v1/images/edits` | 明确 multipart/参考图契约；不将编辑等同扩图 |
| 语音合成 | `/v1/audio/speech` | 绑定 voice、格式和可用参数 |
| 视频等异步媒体 | `/v1/tasks/{pluginKey}` 提交、`/v1/tasks/{taskId}` 查询 | 固定版本插件的 schema、状态和输出已适配；不能通用猜测所有插件 |
| 音乐/变声/克隆/声音设计 | 各自明确接口或任务插件 | 单独适配验收，TTS 不代表这些能力已支持 |

任务插件的路由、参数及输出来自部署版本，旧视频路径和新版通用任务路径不混用。模型目录与 API 版本漂移必须产生可见错误，不静默移除用户参数。平台余额/计费/网关用户管理不进入桌面产品流程，网关实际费用由其部署方管理。

## 持久化与恢复

公开配置 `providers.json` 使用 schemaVersion 与原子写入；仅存连接地址、模型绑定、默认值和密钥引用。生成任务先写本地 TaskStore。异步请求提交前记录 submitting；得到网关任务 ID 后记录 submitted 并完成持久化确认，再开始轮询。恢复时复用原任务 ID 查询，禁止重复提交；提交结果未知需用户处理，不自动重放。

成功以结果文件已落盘且能读取为准。媒体下载不向跨域结果地址转发网关令牌，不接受本地路径作为远程下载地址。取消本地任务与停止轮询不宣称上游任务已取消；只有明确接口与验证结果支持取消时才宣告远端取消。已有节点参数和参考素材校验继续生效，无法上传的参考明确报错。

## 实施与验收

Luna max 子 Agent 分别负责 HTTP 适配与协议测试、配置与凭据测试、原前端配置页与选择器；主 Agent 更新契约、连接 TaskStore/Agent 并集成验证。

先打通模型目录、配置保存、文本与标准图片/TTS，再逐个接入视频插件。测试覆盖无效令牌、超时、参数错误、不支持能力、落盘、任务检查点与恢复、秘密脱敏、未配置不联网、旧路径兼容。mock 测试只证明本地协议处理；每类真实生成仍需用户网关、版本及有效令牌验证。未验证的原目标型号、视频插件和特殊音频能力列作缺口，不能宣称全型号或跨平台安装包验收完成。
