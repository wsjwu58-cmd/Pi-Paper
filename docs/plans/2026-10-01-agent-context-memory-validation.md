# Agent 原代码迁移：上下文、记忆与恢复验收（2026-10-01）

## 本轮实现

直接修改原 `vibepaper-agent-service` TypeScript runtime 与原 `AgentPanel`，Worker 负责通信和生命周期。角色及工具定义仍由原小P profile 和 runtime 提供。平台差异位于 desktop adapter；Web 路径保留原行为。

- 完整请求预算包含系统提示词、工具 schema、引用、本轮输入及历史。128k 模型窗口预留输出及 8k 安全余量；估算采用保守字符规则，并非供应商精确 tokenizer。旧消息按完整用户回合及工具配对裁剪，由真实模型生成有界摘要，写入 Pi 原生 compaction；完整转录保留。压缩保留数为零时不保留最后一轮。
- 原参考节点元数据投影到模型历史及后续压缩，保持低信任数据标签；可见历史仍显示用户原文。摘要每个供应商响应记录独立用量回执，失败摘要的已发生调用也可统计。
- 会话、画布、项目、全局、当日记忆已接原偏好页。项目控制库 schema v4 保存待审核候选；显式审核保存原候选元数据。项目表达优先识别项目范围。自动提示写入失败遵循原 HTTP 路径容错，不中断模型回合。
- 原历史页接本地片段保存、列表和复用；仅复制可见对话，不重放工具或任务，不把导入的历史视为新模型用量。原 Skill 历史卡片恢复可读名称。
- 停止请求从 IPC 直接中止摘要请求和 Pi 回合，不等待普通 Worker 队列；Gateway、Main 检查停止状态，在新的画布副作用前拦截。已开始的写入依赖幂等账本核验，不盲目重放。
- 修复真实工具结果中对象可选 `undefined` 导致 JSONL 拒写。适配器只省略普通对象的可选空属性；数组空值、循环、非有限数、访问器及不受支持的对象仍由 Pi 严格校验拒绝。
- 项目备份/恢复覆盖会话片段、各项目内记忆及候选，恢复后重绑项目身份、终止中断回合并失效旧确认。全局记忆属于用户配置目录，项目备份不包含它；JSON 导出包含全局记忆，但本轮没有新增 JSON 导入流程。

真实 Agnes 测试从系统保护凭据读取 Key，使用隔离项目与隔离用户数据目录。发送的创作请求均为用户自然语言，未注入工具名或内部 ID：

1. 小P问候，创建两个文本节点并正确连线。
2. 创建三个文本分镜与三个图片目标，一对一连接：每个图片仅有一个不同文本来源。
3. 请求生成一个图片目标，出现持久化系统确认；拒绝后 TaskStore 任务数为零。
4. 开始长故事回合后停止，产生 `run_aborted`，没有将中止伪报为完成。
5. 真实会话保存为片段并导入，新会话 Token 为零；会话记忆写入成功。

该回合链路返回 `thinking`、工具开始/完成、确认和中止事件；实际用量为 59,599 Token，9 次模型调用、10 次工具调用。历史响应未包含凭据。此数据是本次隔离测试结果，不代表固定请求开销。

另一次真实摘要调用产生 380 字摘要，保留猫咪短剧目标；关闭并重开原存储后恢复 Pi compaction，原始转录仍有一条消息。摘要实际用量 849 Token、1 次调用，摘要不含凭据。自动触发预算和多段摘要通过定向测试；此真实测试单独验证摘要供应商及落盘/重开路径，未声称真实 128k 压力测试已完成。

调试期间另一次真实文本请求收到 `MODEL_UNAVAILABLE`；后续完整链路成功。首次真实工具回合发现的 `AGENT_SESSION_WRITE_FAILED` 已复现、修正并回归验证。正式代码不保留临时诊断或测试凭据。

## 仍需完成的完整验收

### 随后启动检查

首次直接启动 production 构建发现：原前端从 `/` 导航到 `/workspace` 后，宿主仍只信任根路径，导致项目列表/活动项目 IPC 被拒绝。已将同源可信页面限定为原桌面路由 `/`、`/workspace`、`/history` 与单段画布 ID 路径；相应路由重新加载时返回 SPA 入口。素材、任务输出、任意路由、带凭据 URL 和其他来源仍不能取得 Renderer IPC 权限。3 项边界回归通过；正常关闭重启后，窗口响应正常，启动日志未再出现宿主校验错误。

上述证据证明本轮代码链路接通，不等于所有平台和逐屏 1:1 验收完成。原 Web 与桌面同状态截图/操作录屏、多平台安装包、本地 Agent 模型回合、真实媒体生成全链路和长会话真实压力/中断仍须分别验收。未完成项继续保留为缺口，不以禁用入口、模拟成功或构建通过代替。
