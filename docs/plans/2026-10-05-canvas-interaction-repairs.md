# 画布与 Agent 面板交互修复

## 本轮范围

按用户要求使用三组 Luna / max 子 Agent 修改原前端源码，主 Agent 集成、审查和验证。本轮不处理模型连接失败，不发起真实模型请求。

- 模型菜单使用 body portal 和视口边界定位，厂商与模型两列随可用宽度调整；支持 Escape、外部点击关闭。
- 连线幂等重放不会重复追加同一连线；保存前清理重复视图记录和悬空引用，保留领域校验及可见的无效连线。右键删除先完成待保存快照，再通过本地核心或原 Web DELETE 删除权威连线，成功后更新视图。
- 原节点任务 feed 在 Agent 提交和任务状态变化时刷新；新任务替换旧任务绑定，顶层与嵌套节点状态同步。生成动画和计时使用最新任务，参考连线继续显示蓝色基线上的白光流动。
- 桌面窗口图标收紧原图外部留白，提高任务栏中主体的可见大小，保持原素材文件。
- 文本节点复用原 Markdown 渲染器。支持标题、列表、表格、引用与代码块；HTML 作为文本转义。双击打开全文阅读层，支持文本选择、滚动、Escape、遮罩关闭及焦点管理。Agent 对话默认标题字号保留原值。

## 验证

- 原前端 `npm run build` 通过（保留既有 chunk size / dynamic import 警告）。
- 六个定向 Vitest 文件共 20 项通过：连线幂等重放与悬空引用、删除适配端口、节点状态镜像、最新任务选择与计时、现有编组回归、Markdown 完整正文和 HTML 转义。
- 桌面 `project-store-canvas-validation.test.cjs` 32 项通过：原连线类型矩阵、自连接约束、幂等、权威删除及原版本语义。
- 隔离 Electron 项目交互检查：1426px、670px、320px 视口中的模型菜单均位于边界内；厂商切换及 Escape 可用。右键删除后视图和本地持久画布连线数均为 0。
- 折叠文本节点首次双击和已展开正文双击均打开阅读层；标题、表格、引用、代码块及完整正文可见，Escape 关闭。双击不再冒泡到新建菜单，首击展开造成的 DOM 切换由输出区域的捕获事件处理。
- 隔离任务 fixture 显示生成背景扫描/脉冲、参考图和递增计时。fixture 仅用于 UI 状态检查，未创建供应商任务，不能作为真实模型生成验收。

## 交付边界

本次修改集中在原 `vibepaper-web` 页面、节点和本地适配边界，没有替换为平行桌面页面。应用窗口需重新加载最新构建才能应用 UI 修复；窗口图标调整需重新启动应用。本轮结果不代表整个 Agent 模块已完成 1:1 迁移验收。
