# 用 Codex / Claude Code 操作桌面画布

适用范围：桌面本地 MCP 开发版本及本轮构建包。功能实现与验收状态见[最新验收记录](../verification/2026-10-11-mcp-acceptance/README.md)，已发布的旧安装包不会因源码更新自动获得接口。

## 建立连接

1. 启动桌面应用，选择本地项目并打开原画布创作页。
2. 在“外部 Agent / MCP”设置中启用服务，为 Codex 或 Claude Code 创建独立授权。选择画布读取、编辑、生成提案、任务读取等需要的权限；图片/视频提供方配置权限须单独选择厂商、字段和输入方式。
3. 阅读外部 Agent 的数据发送说明，创建授权后复制桌面实际生成的客户端配置，再返回原画布创作页。配置只包含本机启动路径和公开连接标识，不填写模型 Key。
4. 将对应配置加入客户端的 MCP 设置并启动连接。核对客户端与桌面显示的短码，在桌面批准该连接。
5. 让外部 Agent 读取当前上下文并操作画布。停留在导航/设置页时不能开始新的画布写入或提交生成；已授权的提供方配置请求可在原配置页完成。

每个新桥接进程需要一次桌面连接批准；同一存活连接内的普通工具调用不会逐次询问。修改授权范围、切换项目、撤销授权或重启应用后，旧连接不能自行获得新范围。桌面未运行时客户端会报告不可用。

生成的配置路径随开发目录或安装包位置变化。移动应用后从桌面重新取得配置，不把开发机器路径复制给其他用户。连接配置不要求全局 Node 或启动时通过 npx 下载依赖；实际安装包入口仍按对应平台验收记录判断。

配置中的 `ELECTRON_RUN_AS_NODE="1"` 用于让安装包内置运行时启动独立 stdio 桥接，须保留。它不是 API Key；不要把提供方秘密加入 `args` 或导出的配置。应用级外部环境变量映射只登记变量名，具体值须在启动客户端时的环境中提供。

## 配置图片、视频模型

可向 Agent 提出：

> 帮我查看当前可用的图片和视频提供方。只启用我指定的模型，先保存配置并检查连接，生成前让我在桌面确认。

Agent 先读取公开凭据字段、模型能力和配置 revision，再准备配置。只有已实现的官方适配和能力匹配的启用模型才能使用；厂商显示名称不能当作未经核验的官方模型 ID。

有配置授权时，公开目录还返回该厂商允许的凭据字段、输入方式及不含秘密值的来源引用。环境变量方式由 Agent 从目录选取 sourceRef；引用过期后重新读取，不需要用户把环境变量值贴进聊天。仅有读取权限的连接不会得到这些配置来源。

| 输入方式 | 如何使用 |
| --- | --- |
| 授权的环境变量 | 在桌面把厂商的特定凭据字段映射到确切环境变量名。客户端桥接启动时继承该变量，Agent 只提交桌面登记的不透明来源引用。变量内容不放进连接配置或命令行。启动后新增变量须重启客户端桥接并重新批准连接。 |
| 原配置页输入 | Agent 准备公开配置，用户回到原 API 配置页填写 Key，再完成该配置请求。密码字段只显示本次输入，不能回读保存的 Key。 |
| 外部 Agent 一次性提交 | 仅在桌面明确启用这一输入方式后使用。用户把新 Key 交给外部 Agent，由受限工具写入加密凭据存储。外部聊天、模型上下文或客户端工具日志可能保留原文，VibePaper 无法替外部客户端删除或保证脱敏。 |

没有读取、复制或解密已保存 Key 的 MCP 工具。配置权限按厂商和字段限定；画布编辑权限不包含配置权限。安全存储不可用时拒绝保存，不能降级为明文。

云端配置首次启用或扩大数据发送范围时，须在桌面接受厂商、发送内容与可能费用说明。客户端自报同意不能替代桌面授权。保存成功、真实鉴权检测通过、账号具备某型号权限、实际生成成功是四个不同结果；没有官方安全检测接口时显示不支持检测，不通过收费生成来偷偷测试 Key。

## 操作与生成

可向 Agent 提出：

> 创建三个图片目标节点，分别引用我指定的三个参考节点，每个目标只连到对应参考。先展示生成提案，等我在桌面确认后再生成。

普通节点创建、参数修改、连线和布局按授权范围执行。写入前桌面保存未保存编辑，短暂阻止新编辑，再通过版本校验执行和刷新原画布；保存失败或版本冲突时返回原因，不能用旧整图覆盖当前内容。

生成工具首先返回持久化提案。用户在原 Agent 面板的确认卡中检查来源、目标、模型、输入和覆盖影响后批准，任务才进入本地 TaskStore。连接授权、已保存 Key、厂商披露或工具许可均不能替代这次生成确认。

客户端超时或断线后先查询原 operationId / proposalId，避免重复创建节点或任务。已提交任务不因客户端退出自动取消；任务成功须有可读取的本地结果并在原节点显示。未确认提案在过期、项目/画布版本改变、相关配置修改或桌面重启后失效。

## 当前验收边界

开发版本已通过 128 项桌面专项回归和隔离 Electron 联调。结果读取支持文本分页、输出索引 0–3，以及授权后的图片/视频预览。默认只返回媒体元数据；需明确请求 preview 才发送图片（最多 4 MiB）或视频资源（最多 8 MiB），并受媒体类别授权限制。大文件返回明确错误，仍可在原节点查看。

Agnes 图片与用户指定 Video 2.5 Flash 的真实生成已通过；真实 PNG/MP4 经 MCP 返回的字节与本地文件摘要一致，原节点视频可播放。真实 Codex 已完成本地文本生成、桌面确认和结果读取；独立审查确认核心流程，原自动记录的末尾撤销 QA 误判保留，修正后未重跑。真实客户端自然语言配置和官方媒体全链路仍未验收。Windows 实际安装升级、包内桥接及关闭重开已验证。Claude Code 真实会话按用户要求取消本轮验收，不计作兼容性通过。

协议 fixture、隔离开发实例、真实 Codex/Claude Code 连接、真实官方图片/视频账号生成及安装包分别记录。最新结果见 [2026-10-11 验收记录](../verification/2026-10-11-mcp-acceptance/README.md) 与[功能规格](../specs/desktop-mcp-functional-spec.md)；定向单元测试或构建成功不代表三平台交付已完成。本轮按用户要求先验收 Windows。
