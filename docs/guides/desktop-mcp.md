# 用 Codex / Claude Code 操作桌面画布

适用范围：桌面本地 MCP 开发版本及本轮构建包。功能实现与验收状态见[最新验收记录](../verification/2026-10-11-mcp-acceptance/README.md)，已发布的旧安装包不会因源码更新自动获得接口。

## 建立连接

1. 启动桌面应用，选择本地项目并打开原画布创作页。
2. 在“外部 Agent / MCP”设置中启用服务，为 Codex 或 Claude Code 创建独立授权。选择画布读取、编辑、生成提案、任务读取等需要的权限；图片/视频提供方配置权限须单独选择厂商、字段和输入方式。
3. 阅读外部 Agent 的数据发送说明，创建授权后复制桌面实际生成的客户端配置，再返回原画布创作页。配置只包含本机启动路径和公开连接标识，不填写模型 Key。
4. 将对应配置加入客户端的 MCP 设置并启动连接。已配置范围内自动鉴权，无须短码核对或返回桌面批准连接。
5. 让外部 Agent 读取当前上下文并操作画布。停留在导航/设置页时不能开始新的画布写入或提交生成；已授权的提供方配置请求可在原配置页完成。

勾选“配置模型”会同时选中其必需的“读取模型配置”，供 Agent 获取公开字段、型号与配置版本；勾选“读取媒体”会同时选中“读取任务”。这两项依赖会在授权页显示，厂商和媒体类别仍须单独指定。取消配置权限后，尚未完成的凭据输入方式和环境变量草稿不会进入只读授权。

已经创建的旧授权不会自动扩大范围；若旧授权缺少上述依赖权限，在设置中撤销后按所需范围重新创建，并更新客户端配置。

连接、提供方配置、安全模型检测及普通画布操作不要求人工确认。仅生成时在 Codex/Claude Code 客户端显示确认表单，桌面不再重复询问。客户端须支持 MCP form elicitation；不支持时明确拒绝生成。修改范围、切换项目或撤销后，旧连接不能自行获得新范围；重启会轮换本地连接凭证。桌面未运行时客户端报告不可用。

生成的配置路径随开发目录或安装包位置变化。移动应用后从桌面重新取得配置，不把开发机器路径复制给其他用户。连接配置不要求全局 Node 或启动时通过 npx 下载依赖；实际安装包入口仍按对应平台验收记录判断。

配置中的 `ELECTRON_RUN_AS_NODE="1"` 用于让安装包内置运行时启动独立 stdio 桥接，须保留。它不是 API Key；不要把提供方秘密加入 `args` 或导出的配置。应用级外部环境变量映射只登记变量名，具体值须在启动客户端时的环境中提供。

## 配置图片、视频模型

可向 Agent 提出：

> 帮我查看当前可用的图片和视频提供方。只启用我指定的模型，先保存配置并检查连接，生成前在这里让我确认。

Agent 先读取公开凭据字段、模型能力和配置 revision，再准备配置。只有已实现的官方适配和能力匹配的启用模型才能使用；厂商显示名称不能当作未经核验的官方模型 ID。

有配置授权时，公开目录还返回该厂商允许的凭据字段、输入方式及不含秘密值的来源引用。环境变量方式由 Agent 从目录选取 sourceRef；引用过期后重新读取，不需要用户把环境变量值贴进聊天。仅有读取权限的连接不会得到这些配置来源。

| 输入方式 | 如何使用 |
| --- | --- |
| 授权的环境变量 | 在桌面把厂商的特定凭据字段映射到确切环境变量名。客户端桥接启动时继承该变量，Agent 只提交桌面登记的不透明来源引用。变量内容不放进连接配置或命令行。启动后新增变量须重启客户端桥接，重连自动鉴权。 |
| 原配置页输入 | Agent 准备公开配置，用户回到原 API 配置页填写 Key，再完成该配置请求。密码字段只显示本次输入，不能回读保存的 Key。 |
| 外部 Agent 一次性提交 | 仅在桌面明确启用这一输入方式后使用。用户把新 Key 交给外部 Agent，由受限工具写入加密凭据存储。外部聊天、模型上下文或客户端工具日志可能保留原文，VibePaper 无法替外部客户端删除或保证脱敏。 |

没有读取、复制或解密已保存 Key 的 MCP 工具。配置权限按厂商和字段限定；画布编辑权限不包含配置权限。安全存储不可用时拒绝保存，不能降级为明文。

云端配置会记录厂商、发送内容与可能费用说明，不要求批准披露卡；工具不能扩大已选的厂商/字段范围。保存成功、真实鉴权检测通过、账号具备某型号权限、实际生成成功是四个不同结果；没有官方安全检测接口时显示不支持检测，不通过收费生成来测试 Key。

## 操作与生成

可向 Agent 提出：

> 创建三个图片目标节点，分别引用我指定的三个参考节点，每个目标只连到对应参考。先在这里展示生成确认，批准后再生成。

普通节点创建、参数修改、连线和布局按授权范围执行。写入前桌面保存未保存编辑，短暂阻止新编辑，再通过版本校验执行和刷新原画布；保存失败或版本冲突时返回原因，不能用旧整图覆盖当前内容。

生成工具先准备持久化提案，再由桥接在客户端显示确认表单。核对目标、模型、输入、覆盖影响和可能费用后批准，任务才进入本地 TaskStore。拒绝、确认超时以及提交前取消或断线不提交新任务；请求已经进入提交后断线，结果可能未知，须先查询账本。连接、已保存 Key、厂商信息或普通工具许可均不能替代这次确认；确认表单不会索取 Key。内置 Agent 的原桌面确认保持不变。

桌面生成的 Codex 配置将本服务的普通工具设为直接允许，生成使用上述协议表单单独确认。客户端或组织的更严格策略仍由客户端管理，应用不能替用户绕过。不要把所有写工具伪装成只读来消除提示。

客户端超时或断线后先查询原 operationId / proposalId，避免重复创建节点或任务。已提交任务不因客户端退出自动取消；任务成功须有可读取的本地结果并在原节点显示。未确认提案在过期、项目/画布版本改变、相关配置修改或桌面重启后失效。

同一提案已有确认表单等待时，重复准备请求会返回“已有待确认请求”，不会再打开表单或替换原确认。请完成原表单或查询原操作；断线使原连接的未完成确认失效，重连后需按当前状态处理。

Agnes 图片和视频的创建请求只发送一次。收到限流、网关错误、队列已满或网络超时时，不自动重发可能付费的创建请求；已有视频任务的只读状态查询仍可退避重试。响应丢失时不能据此判断厂商未创建任务，应先核对任务与厂商记录，再决定是否重新生成。

Agnes Flash 视频收到上游任务标识后会先保存检查点，再查询状态。桌面重启后，有此检查点的任务继续查询原视频，不重新生成；提交前检查点保存失败则不发送创建请求。只有“提交中”而未保存上游标识的任务，结果视为未知，禁止自动或手工重试原任务。当前这项保守限制也适用于创建端返回 503 的情况；核实厂商记录后若仍需重新生成，须作为新的生成请求再次确认。图片的同步生成没有可恢复的上游任务标识，同样不会因中断自动重发。

Ark Seedance 视频同样保存上游标识并在重启后继续查询；这不代表供应商支持取消任务。关闭本地轮询时，上游可能仍在生成和计费。

## 当前验收边界

若 MCP 在桌面启动前连接，工具列表暂时只有应用未运行状态的上下文工具。打开已授权画布后，可让 Agent 重试读取上下文；首次鉴权成功的普通调用会通知客户端刷新工具目录，不会重放生成。客户端若未响应目录变更通知，再重启该 MCP 服务。

2026-10-17 改为客户端生成确认，原桌面短码/披露/生成确认方式的历史测试不能替代新流程验收。历史开发版本的专项回归、真实媒体与安装包记录仍保留原结论。结果读取支持文本分页、输出索引 0–3，以及授权后的图片/视频预览。默认只返回媒体元数据；需明确请求 preview 才发送图片（最多 4 MiB）或视频资源（最多 8 MiB），并受媒体类别限制。大文件返回明确错误，仍可在原节点查看。

历史 Agnes 图片与指定 Video 2.5 Flash 的真实生成、PNG/MP4 的 MCP 摘要比对与原节点播放已通过。新策略下，真实 Codex 已完成自动连接、自然语言配置、一次客户端表单经当前会话转交用户确认后的真实图片生成、预览摘要比对和原节点显示；续验复用同一笔成功图片。这里的确认由验收宿主转交，不代表 Codex 桌面原生弹窗已通过视觉验收；新流程的视频完整回合仍未通过。

Windows 10-17 诊断包卸载清理通过；10-19 正式包的升级及正常启动、关闭、重开通过，但实际卸载后仍留有两个 HKCU 注册项，用户资料内容不变。随后补充的清理只删除能证明属于当前安装目录的注册项，12 个独立测试通过不能替代修复包的手工卸载验收。旧失败证据继续保留。Claude Code 真实会话按用户要求取消，不计作兼容性通过。
